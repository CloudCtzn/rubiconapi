# RubiconAPI

A suite of text intelligence APIs built on AWS serverless infrastructure.

Cross it once, you never go back. 

---

## APIs

| API     | Description                                      | Status         |
|---------|--------------------------------------------------|----------------|
| Augur   | Sentiment analysis — score the emotion in text   | ✅ Live        |
| Consul  | Text summarization — condense long content       | 🔜 Coming Soon |
| Specula | Keyword extraction — surface recurring themes    | 🔜 Coming Soon |

---

## Access

All APIs are available on RapidAPI. Each API can also be self-hosted 
on your own AWS account using the Terraform code in each folder.
